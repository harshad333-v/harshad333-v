## 👋 About me

I'm **Harshad Raj Gupta**, a Computer Science and Engineering student at **ITM University, Gwalior**. I enjoy turning ideas into working software and exploring how intelligent systems can solve practical problems.

My current interests sit at the intersection of **software engineering, applied machine learning, and AI-powered applications**. I work across the stack—from designing web applications and APIs to building data pipelines, training ML models, and experimenting with retrieval-augmented generation (RAG) and local language models.

- 🎓 B.Tech in Computer Science & Engineering — ITM University, Gwalior
- 🧠 Exploring applied AI, machine learning, LLM applications, and RAG systems
- 💻 Building with Python, JavaScript, React, Node.js, Django, and Flask
- 📊 Interested in data analytics, model evaluation, and practical ML engineering
- 🤝 Open to meaningful collaborations, open-source work, and learning from strong engineering teams

> **My approach:** understand the problem, build a working solution, measure it, and improve it.
